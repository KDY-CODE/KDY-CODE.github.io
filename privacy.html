Finshadow Personal Readonly 隱私政策

本頁撰寫日期：2026年11月7日。內容只描述這個私人工具目前的做法。

Finshadow Personal Readonly 只供擁有人私人使用，用來對帳。本政策說明它如何透過 Google API 讀取資料、資料用在哪裡，以及擁有人可以如何停止程式並撤銷授權。

程式在哪裡執行

程式在 Grok Bot 的私有雲端電腦上執行，不是在擁有人家中的個人電腦上執行。讀取銀行帳單與試算表時，透過 Google API 進行。

Google 權限實際可以讀到什麼

工具使用下面兩項唯讀權限。縮小到特定郵件來源與指定試算表的，是程式邏輯。Google 同意畫面授予的範圍比這個邏輯更寬。

gmail.readonly

https://www.googleapis.com/auth/gmail.readonly

這項授權可以讀取該 Google 帳戶信箱中的郵件。它不能寄信，也不能修改郵件。讀取範圍是信箱，不是單一寄件者，也不是單一信件。程式邏輯才把處理限制在特定來源，用來取得銀行帳單。

spreadsheets.readonly

https://www.googleapis.com/auth/spreadsheets.readonly

這項授權可以讀取該帳戶能夠開啟的 Google 試算表。它不能修改試算表。這不是「只能讀取單一一張試算表」的 Google 範圍。程式邏輯才把讀取限制在擁有人指定的正本。

本網站不提供、也不收取 Google 權杖。授權是否已經存在，以擁有人的 Google 帳戶顯示為準。

資料用在哪裡

從 Gmail 與 Google 試算表讀到的內容，用來做擁有人自己的對帳。

  • 個人資料不公開在這個網站上。
  • 個人資料不出售。
  • 這些資料不用於廣告，也不用於信用評估。
  • 透過 Google API 取得的資料，遵循 Google API Services User Data Policy，包括 Limited Use 要求。
  • 這些資料不用於一般模型訓練。

必要時的 AI 協助

為了完成對帳，必要的例外資料可能經 AI 協助處理。資料因此可能離開程式所在的私有雲端電腦，交給協助處理的一方。本政策據此說明，不把資料流寫成零外傳，也不寫成處理過程絕無第三方。

這項 AI 協助是對帳處理的一部分。Google 使用者資料不用來訓練一般模型。

存放、停止、撤銷與刪除

受限文件與憑證以私人方式存放，不放進這個公開網站或公開 repo。目前沒有公開的保留天數。本頁沒有記載已實施的安全措施、固定刪除期限或外部審核。

以目前的做法，擁有人可以：

  • 停止這個私人程式。
  • 撤銷 Google 帳戶對本工具的授權：https://myaccount.google.com/permissions
  • 刪除工作目錄。

撤銷授權之後，程式不能再憑該授權呼叫 Google API。工作目錄裡已經存在的檔案，要由擁有人刪除該目錄，才會從那個工作位置移除。

這個公開網站

這個網站只有靜態說明頁，由公開的 GitHub 倉庫透過 GitHub Pages 提供。頁面沒有登入、沒有表單、沒有追蹤分析、沒有 JavaScript SDK，也沒有向外部載入字型或圖片。網站不連接金融資料。

頁面檔案本身不收集輸入內容，因為頁面上沒有可以送出的欄位。GitHub Pages 仍會依主機的一般方式處理連線。本政策不把主機的連線紀錄說成不存在。

Google Search Console 的 HTML 驗證檔尚未取得，所以這個網站現在沒有放該檔案。本頁是工具說明與隱私政策，沒有宣布 Google OAuth 的發布或審查已經完成。

English summary

This summary states the same facts as the Traditional Chinese policy above.

Finshadow Personal Readonly is a private reconciliation tool for its owner. The program runs on Grok Bot’s private cloud computer. It does not run on the owner’s home computer. It reads data through Google APIs.

https://www.googleapis.com/auth/gmail.readonly can read mail in the Gmail mailbox. It does not send or change mail. The scope is the mailbox, not one sender and not one message. Program logic is what limits processing to particular sources so the tool can obtain bank statements.

https://www.googleapis.com/auth/spreadsheets.readonly can read Google Sheets spreadsheets the account can open. It does not edit them. The scope is not limited to a single spreadsheet. Program logic is what limits reading to the master copies the owner designates.

The data is used for the owner’s own reconciliation. It is not published on this website, sold, used for advertising, or used for credit assessment. Google API user data is handled under the Google API Services User Data Policy, including Limited Use, and is not used to train general models.

Where needed for reconciliation, exceptional data may be processed with AI assistance. That data may leave the private cloud computer and be handled by the party providing that assistance. This policy does not describe the flow as zero transmission or as involving no third party. AI assistance here is task processing, not general model training.

Restricted documents and credentials are stored privately and are not placed in this public website. No retention period is published. This page does not record an implemented security control, a fixed deletion deadline, or an external audit. The owner can stop the program, revoke access at https://myaccount.google.com/permissions, and delete the working directory. After revocation, the program can no longer call Google APIs with that grant. Files already in the working directory are removed from that location when the owner deletes the directory.

This website is static GitHub Pages content. It has no sign-in, no forms, no analytics, no JavaScript SDK, and no external fonts or images. It does not connect to financial data. A Google Search Console HTML verification file has not been issued and is not included. This page does not state that Google OAuth publication or review is complete.
